# Sobre o Projeto
Projeto criado com o intuito de fornecer uma aplicação simples para troca de mensagens com chatbot.
O projeto utiliza fastapi para a aplicação backend, juntamente com a biblioteca de modelos IA do gemini.
Para o frontend é utilizado typescript por conta da sua versatilidade e nele é construida todas as ferramentas necesssárias para possibilitar a utilização dos recursos disponibilizados pela API backend.
